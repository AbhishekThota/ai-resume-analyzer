# AI Resume Analyzer

A beginner-friendly AI web app that compares resumes with job descriptions.

## Features
- Resume & job description matching
- Skill gap analysis
- AI-generated feedback

## Tech Stack
- Python
- Flask
- OpenAI API
- HTML & CSS

## How to Run
1. Install dependencies: pip install -r requirements.txt
2. Add your OpenAI API key in app.py
3. Run: python app.py
4. Open browser: http://127.0.0.1:5000/
